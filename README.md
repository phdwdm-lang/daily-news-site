# daily-news-site

一个可分享的 AI 每日简报 Skill：采集三家 newsletter 和 Follow Builders，生成固定版式的本地信息站，并保留来源、素材与实际浏览验收记录。

首次使用默认由代理读取宿主允许访问的近期会话摘要，展示可能相关的主题与身份信息，让你逐项确认、编辑或忽略；只有你确认的内容才进入私人档案。读取工具不可用时，可只用当前对话、手动填写，或直接跳过个人化。后续也可以指定自己的任务资料。公共重点按资讯价值选择，个人关联单独判断。

## 使用前准备

- **首发实际验收平台：macOS。** Linux/WSL 尚未完成完整浏览验收；原生 Windows 因 Unix 文件锁和符号链接依赖不受支持。
- Python **3.11+**、Node.js **18+**、curl。采集和渲染使用内置模块，不需要 npm install、pip install 或资讯 API 密钥。
- 能读写本地工作区、运行脚本、查看图片的代理宿主，以及可连接的 **Ego Lite / ego-browser**。这是代理工作流，仍需要代理进行编辑、图片判断及浏览验收。
- 网络需能访问三家 newsletter、GitHub raw feed 及所选原文/图片站。历史回采还需 GitHub API；公开接口可能限流或变更。

安装上述软件请使用各自官方安装方式；本 Skill 不会自动安装软件、修改调度或公开托管。

## 安装与首次初始化

下载本仓库的完整目录，把它作为一个 Skill 目录安装到代理宿主支持的位置。对于按目录发现 Skill 的宿主，将整个文件夹命名为 `daily-news-site` 并安装到其 skills 目录；不能只复制 SKILL.md。现有同名 Skill 先由你自行备份和选择，不自动覆盖。

也可以先在下载目录中使用脚本检查，不必立即安装到宿主：

```sh
python3 scripts/doctor.py
python3 scripts/setup.py --workspace '/你选择的位置/我的 每日信息站'
python3 scripts/doctor.py --project '/你选择的位置/我的 每日信息站' --network
```

命令里的路径换成你自己的。支持中文和空格；工作区必须是新目录。重复初始化已建立的工作区会返回 `unchanged`，保留档案、设置和数据；已有的其他目录会拒绝写入。页面默认白天主题，右上角按钮可切换夜间主题并记住本机偏好；日期展示统一使用北京时间。

`doctor` 真正检查解释器版本、curl、模板、Alpine、写权限、Unix 锁、符号链接切换和目录落盘；`--network` 使用实际 Node fetch 检查六个公开来源入口。它能检测 Ego 命令运行时，但不会把“可执行文件存在”当作“浏览器已完成验收”。宿主读图、浏览器连接和当期候选仍需实际确认。

## 开始日更

在代理对话里指定新工作区并调用：

> 使用 $daily-news-site 更新今天的简报，工作区是我刚创建的目录。请先引导我初始化个人参考资料。

完整流程与个人化方法见 [SKILL.md](SKILL.md)。软件初始化与每期运行是两件事：工作区内 `python3 scripts/workflow.py init` 只创建本次运行，不会重新安装软件或重置个人资料。

通过候选浏览验收和来源签收后，入口位于工作区 `site/current/index.html`。如需本地浏览服务，在**新工作区**运行：

```sh
python3 -m http.server 18867 --bind 127.0.0.1 --directory site/current
```

打开 http://127.0.0.1:18867/ 。浏览服务不是公网托管。没有待办、没有 Pages 权限、没有其他资讯 Skill，都可以使用通用模式；资讯采集返回并不等于网站已更新。

## 私人数据与来源

工作区 `.daily-news/` 保存配置、确认后的档案和候选审核。真实新闻输入、素材、审计与浏览证据保存在工作区，不包含在本仓库中。不要将自己的整个工作区作为 Skill 发布；仓库提供的 `.gitignore` 默认忽略这些运行数据。

来源失败、上下文不足和无合适配图会如实说明；全空不更新。发布前门禁绑定真实输入、候选和截图，失败保留上一版；审计不能替代实际的编辑和看图。
