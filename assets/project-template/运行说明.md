# 运行说明

首次软件初始化已经完成。`python3 scripts/workflow.py init` 创建一次新的日更运行；之后根据返回的运行目录执行 `collect`、`packet` 和检查点。完整编辑与门禁命令见 `skills/daily-news-site/SKILL.md` 及其 `references/run-audit.md`。

无个人资料时 `context.mode` 为 `none`：公共重点、速览和 Builders 仍可使用，个人栏为空。个人资料候选不是确认记忆。代理须等用户确认，或接受其修改后再保存。

候选、来源与素材改变后重新浏览签收。已签收内容通过 `scripts/daily_site.py publish --audit ...` 提交后才产生 `site/current`。失败保留旧入口；同日修订按规则使用 `--replace`。仅返回采集结果、生成工作稿或候选都不代表完成发布。

本地浏览命令：`python3 -m http.server 18867 --bind 127.0.0.1 --directory site/current`。浏览服务关闭不会删除已保存文件。

页面初次打开默认白天主题，右上角按钮可切换夜间主题并保留本机偏好；浏览验收须覆盖两套主题下的正文、卡片、侧栏、图片及窄屏。

需要维护代码时运行 `python3 -m unittest discover -s tests -v`。日常纯内容更新用字段、来源、素材与实际浏览验收。线上托管与自动运行需独立配置和验证；本工作区不会自动创建它们。
